¿Qué es la ciberseguridad?

Definición, Aplicación Real y Tríada CIA

Es el conjunto de técnicas, herramientas, procesos y medidas que se utilizan para proteger sistemas informáticos, redes, aplicaciones y datos digitales.

Por ejemplo, la ciberseguridad sirve para:

  • Evitar que alguien robe tu contraseña de Instagram.
  • Proteger los datos bancarios y las tarjetas de crédito.
  • Impedir que un virus dañe tu computadora.
  • Evitar que una empresa pierda información confidencial.
  • Proteger los servidores de un hospital, una escuela o un gobierno.
  • Detectar y responder a ataques informáticos.

Los tres pilares de la ciberseguridad

Se conocen como la tríada CIA, por sus siglas en inglés (Confidentiality, Integrity, Availability):

👁️‍🗨️
Confidencialidad

Solo las personas autorizadas pueden acceder a la información.

Ejemplo: Nadie debería poder leer tus mensajes privados sin permiso.
⚖️
Integridad

Los datos deben mantenerse correctos y no ser modificados de manera no autorizada.

Ejemplo: Nadie debería alterar tus calificaciones en una base de datos escolar.
⚡
Disponibilidad

Los sistemas y la información deben estar accesibles cuando se necesiten.

Ejemplo: Una página web debe seguir funcionando aunque reciba muchas solicitudes.

Los principales tipos de ciberataques

Mecanismos de Compromiso más Habituales
1. Phishing

El atacante se hace pasar por una empresa, un banco o una persona conocida para conseguir contraseñas, información bancaria o códigos de acceso.

Ejemplo: Recibís un mensaje falso que dice que tu cuenta será bloqueada si no ingresás de inmediato a un enlace fraudulento.
2. Ransomware

Malware que cifra archivos o bloquea sistemas informáticos para exigir el pago de un rescate financiero.

Importante: Pagar el rescate nunca garantiza que los atacantes vayan a recuperar o devolver tus datos.
3. Virus, gusanos y troyanos
  • Virus: Se inserta en archivos o programas y se propaga cuando el usuario los ejecuta.
  • Gusano: Se propaga automáticamente entre sistemas por red sin necesidad de insertarse en otro archivo.
  • Troyano: Se presenta como algo legítimo o útil, pero oculta funciones destructivas o maliciosas.
4. Ataques DoS y DDoS

Sobrecargan un servidor o servicio con un aluvión masivo de solicitudes o tráfico basura para impedir que funcione normalmente. Un DDoS (distribuido) utiliza miles de dispositivos o fuentes comprometidas (botnets).

5. Explotación de vulnerabilidades

Consiste en aprovechar errores de software, configuraciones incorrectas o sistemas sin actualizar para acceder a información confidencial o ejecutar acciones no autorizadas mediante exploits.

6. Ingeniería social

Manipula psicológicamente a las personas para que revelen contraseñas, transfieran dinero o ejecuten acciones peligrosas. Incluye estafas por llamadas (vishing), mensajes (smishing) y suplantación de identidad.

7. Ataques a contraseñas

Incluyen adivinar combinaciones (fuerza bruta), ataques por diccionario, uso de credenciales filtradas en brechas públicas (credential stuffing) o engaños para que la víctima las entregue.

⚠️
Otros ataques importantes: La interceptación de comunicaciones (Man-in-the-Middle), la suplantación de direcciones IP/DNS (spoofing), el robo o secuestro de sesiones (session hijacking), los ataques contra aplicaciones web y los intentos de comprometer la cadena de suministro de software (supply-chain attacks).

¿Cómo protegerte de los ciberataques?

Buenas Prácticas de Defensa y Lista Interactiva

No existe una protección 100% infalible, pero podés reducir muchísimo el riesgo adoptando hábitos defensivos consistentes:

🔑 Contraseñas seguras

Usá contraseñas largas y complejas. No repitas la misma clave en varias cuentas. Utilizá un gestor de contraseñas confiable (como Bitwarden) y nunca compartas códigos de recuperación.

📱 Autenticación multifactor (MFA)

Añade una segunda prueba de identidad, como una aplicación de autenticación (Google Authenticator, Aegis) o una llave de seguridad FIDO2. Es sumamente superior a depender solo de una contraseña.

🔄 Actualizaciones

Mantené actualizado el sistema operativo, el navegador, tus apps y el router hogareño. Los parches corrigen vulnerabilidades conocidas activamente explotadas.

💾 Copias de seguridad (Backups)

Hacé copias periódicas de tus archivos importantes. Guardá al menos una copia desconectada (offline) de tu dispositivo principal y verificá con frecuencia que podés restaurarla.

🎯 Detección de engaños

Desconfiá de mensajes urgentes, premios inesperados, enlaces extraños y archivos adjuntos no solicitados. Verificá la dirección del remitente y entrá siempre desde los sitios oficiales.

📶 Seguridad de la red

Usá WPA2-AES o WPA3 en el Wi-Fi, una contraseña robusta para el router y desactivá funciones de administración remota o WPS que no necesites.

Redes informáticas: lo que necesitás entender

Fundamentos de Comunicación y Puertos Comunes

La ciberseguridad está estrechamente relacionada con las redes, porque los dispositivos se comunican continuamente entre sí para intercambiar paquetes de datos.

🌐 Conceptos Principales de Redes:
  • Dirección IP: Identifica una interfaz de red lógica dentro de una red IP (ej. IPv4 / IPv6).
  • Dirección MAC: Identificador físico único de una tarjeta de red a nivel de enlace de datos (Capa 2).
  • Router: Dispositivo que conecta distintas redes e intercomunica paquetes entre ellas (Capa 3).
  • Switch: Conecta múltiples dispositivos dentro de una misma red local (LAN).
  • DNS: Sistema que traduce nombres de dominio legibles (ej. example.com) a direcciones IP numéricas.
  • DHCP: Protocolo que asigna automáticamente configuraciones de red, incluidas direcciones IP y puertas de enlace.
  • Puerto: Identifica un punto lógico de comunicación específico para un servicio en un host (0 a 65535).
  • TCP: Protocolo orientado a conexión confiable, con entrega ordenada y retransmisiones de paquetes perdidos.
  • UDP: Protocolo ligero sin conexión previa que envía datagramas de manera rápida (usado en streaming y juegos en tiempo real).
  • HTTPS: Protege la navegación web mediante TLS, asegurando confidencialidad, integridad y autenticación del servidor.
  • VPN: Crea un túnel cifrado entre dispositivos o redes; protege el tránsito local pero no te vuelve automáticamente anónimo ni elimina todos los riesgos.

Criptografía: cómo se protege la información

Cifrado, Funciones Hash y Firmas Digitales

La criptografía utiliza técnicas matemáticas avanzadas para proteger datos, verificar identidades y detectar modificaciones.

🔐 Cifrado

Transforma datos legibles en datos ilegibles (criptograma) que requieren una clave secreta para volver a recuperarse.

Ejemplo: Protege el contenido de chats en tránsito y archivos en discos duros.
#️⃣ Hash

Produce una huella digital matemática de longitud fija a partir de los datos. Se usa para verificar integridad y almacenar contraseñas seguras mediante funciones con salting (como bcrypt/argon2).

Ejemplo: SHA-256 es una función hash criptográfica, pero un hash rápido simple sin protección no basta para guardar claves.
🔑 Criptografía asimétrica

Utiliza un par de claves matemáticamente vinculadas: una clave pública (compartible) y una clave privada (secreta). Permite comunicaciones seguras y firmas digitales.

✍️
Firma digital: Permite verificar la autenticidad de un documento o mensaje y detectar alteraciones, siempre que las claves y su validación mediante certificados sean de confianza.
⚡
Una diferencia esencial: Cifrar no es lo mismo que aplicar un hash. El cifrado está diseñado para ser reversible (recuperar los datos con la clave adecuada); un hash criptográfico normal está diseñado para ser irreversible en un solo sentido.

Seguridad de aplicaciones y páginas web

Vulnerabilidades OWASP y Seguridad en Videojuegos

Si desarrollás páginas web, aplicaciones o videojuegos (como nuestro proyecto Be On Beat), necesitás proteger el código y los datos:

Vulnerabilidades críticas que debés conocer:
  • SQL Injection: Entradas de usuario manipuladas que alteran consultas directas a una base de datos.
  • XSS (Cross-Site Scripting): Ejecución de scripts maliciosos en el navegador de la víctima dentro del contexto de una página web confiable.
  • CSRF: Acciones no deseadas realizadas aprovechando la sesión previamente autenticada de la víctima.
  • Control de acceso defectuoso: Permite acceder a datos o funciones administrativas que deberían estar restringidos.
  • Mala gestión de sesiones: Facilita el secuestro o reutilización indebida de tokens y cookies de sesión.
  • Exposición de secretos: Contraseñas, tokens JWT o API Keys guardados en texto plano en repositorios o código público.
  • Dependencias vulnerables: Librerías y paquetes de terceros que contienen fallas de seguridad conocidas.

¿Cómo prevenirlas?

  • Validá y sanitizá todos los datos recibidos, pero no dependas únicamente de la validación del lado cliente.
  • Usá consultas parametrizadas o Prepared Statements para interactuar con bases de datos.
  • Aplicá el principio de privilegios mínimos y comprobaciones rigurosas de autorización en el servidor.
  • Protegé las sesiones, activá directivas seguras en cookies (HttpOnly, Secure, SameSite) y tokens.
  • Nunca almacenes contraseñas en texto plano; usá algoritmos robustos con salt (bcrypt, Argon2).
  • Mantené las dependencias actualizadas revisando auditorías periódicas (npm audit, Dependabot).
  • Guardá secretos en variables de entorno seguras fuera del código fuente.
  • Realizá pruebas de seguridad funcionales antes de publicar la aplicación.
🎮
Si trabajás con Unity, esto también importa: Nunca confíes ciegamente en el cliente para determinar por sí solo puntuaciones, compras, recompensas o resultados que deban ser válidos en un servidor. Un jugador puede manipular o modificar el código compilado que se ejecuta en su propio dispositivo.

¿Qué es el hacking ético?

Sombreros de la Ciberseguridad y Fases de Pentesting

El hacking ético consiste en evaluar la seguridad de sistemas informáticos con autorización formal para descubrir debilidades antes que los atacantes y ayudar a remediarlas.

No todo hacker tiene intenciones maliciosas. La diferencia reside en la autorización, el propósito y las acciones:

🎩 White Hat — Hacker Ético

Prueba sistemas dentro de un alcance formalmente autorizado, documenta fallas y asiste a las empresas para solucionarlas.

🧢 Black Hat — Hacker Malicioso

Utiliza técnicas y exploits con fines ilícitos: robar información, extorsionar, dañar infraestructura o lucrar sin autorización.

🕵️ Gray Hat — Zona Gris

Investiga sistemas sin autorización previa, aunque no busque causar daño. La intención no vuelve automáticamente legales sus actos.

¿Cómo se realiza una prueba de penetración (Pentest)?

  1. Definir el alcance y obtener autorización: Establecer contractualmente qué sistemas pueden auditarse y cuáles quedan excluidos.
  2. Reconocimiento: Recopilar información pública y permitida sobre el objetivo (OSINT, DNS, hosts).
  3. Análisis: Identificar servicios activos, puertos abiertos, configuraciones y posibles fallas.
  4. Validación controlada: Comprobar si las vulnerabilidades son reales sin exceder los límites acordados ni dañar datos.
  5. Informe: Documentar detalladamente las evidencias técnicas, nivel de riesgo y recomendaciones de mitigación.
  6. Corrección y nueva prueba (Re-testing): Verificar que las remediaciones aplicadas hayan neutralizado los problemas.
⚖️
Regla fundamental: Nunca pruebes contraseñas, escanees agresivamente, explotes fallas o intentes acceder a sistemas ajenos sin autorización explícita y por escrito. Para aprender, utilizá laboratorios diseñados específicamente para practicar de forma legal.

Herramientas de ciberseguridad que conviene conocer

Utilidades de Diagnóstico, Análisis y Auditoría

No necesitás dominarlas todas al principio. Lo fundamental es comprender el propósito de cada una:

🦈 Wireshark

Analizador de paquetes de red en tiempo real. Permite inspeccionar protocolos a fondo y detectar tráfico inusual. Indispensable para aprender redes.

🧭 Nmap

Escáner de redes que descubre hosts activos, puertos abiertos y versiones de servicios en sistemas autorizados. Ayuda a inventariar la superficie expuesta.

🎯 Burp Suite

Proxy interceptor HTTP/HTTPS para evaluar la seguridad de aplicaciones web. Permite modificar peticiones y analizar respuestas.

🐉 Kali Linux

Distribución de Linux orientada a auditorías de seguridad, informática forense y pentesting. Es un kit de herramientas, no un requisito obligatorio para ser hacker.

🛡️ OWASP ZAP

Herramienta libre y de código abierto para escanear y evaluar vulnerabilidades en aplicaciones web durante el desarrollo.

💻 Terminal de Linux

La interfaz de comandos para administrar archivos, permisos, servicios y automatizar tareas. Es una competencia esencial en la industria técnica.

También existen herramientas para detectar malware (antivirus/EDR), gestionar incidentes (SIEM), analizar binarios y centralizar logs. Una herramienta por sí sola no garantiza seguridad: hay que saber interpretar técnicamente sus resultados.

¿Qué ramas existen dentro de la ciberseguridad?

Especialidades y Áreas Profesionales

No todo el trabajo consiste en hackear sistemas. Existen diversas ramas complementarias:

🛡️ Blue Team — Defensa

Protege la infraestructura, monitorea alertas en tiempo real, investiga eventos sospechosos y endurece las defensas organizacionales.

⚔️ Red Team — Ataque Simulado

Simula tácticas, técnicas y procedimientos de adversarios reales (TTPs) para medir la efectividad de las defensas bajo reglas acordadas.

🔍 Análisis Forense Digital

Examina discos, memorias volátiles y registros para reconstruir incidentes de seguridad y preservar la cadena de custodia de evidencias.

🦠 Análisis de Malware

Desensambla y analiza código malicioso en entornos aislados (sandboxes) para comprender sus capacidades y generar firmas de detección.

☁️ Seguridad en la Nube

Asegura infraestructuras en plataformas como AWS, Azure y GCP, gestionando políticas IAM, cifrado y contenedores.

💻 Seguridad de Aplicaciones (AppSec)

Integra controles de seguridad en el ciclo de vida del software (DevSecOps), audita repositorios y ayuda a escribir código resiliente.

Otras áreas incluyen gestión de riesgos, auditoría y cumplimiento normativo (GRC), respuesta a incidentes (CSIRT/CERT), seguridad industrial (OT/SCADA), privacidad e inteligencia de amenazas (Threat Intelligence).

¿Qué hacer si sufrís un ciberataque?

Protocolo de Contención, Recuperación y Denuncia

Si sospechás que comprometieron una cuenta tuya, infectaron tu computadora o accedieron a tus datos, actuá con rapidez y serenidad:

1. Contené el problema

Si hay indicios de malware activo o intrusión, desconectá el equipo de la red Wi-Fi y cableada de inmediato. No borres archivos ni reinstales todo a ciegas si el incidente puede necesitar investigación forense.

2. Protegé tus cuentas

Desde un dispositivo limpio y confiable, cambiá las contraseñas de las cuentas comprometidas, empezando por tu correo electrónico principal. Cerrá todas las sesiones activas y revocá accesos sospechosos.

3. Contactá a las entidades

Si detectás movimientos bancarios o compras no autorizadas, comunicate de inmediato con el banco por sus canales oficiales. Si el ataque afecta a una organización, avisá al equipo de seguridad de la misma.

4. Guardá evidencias y recuperate

Conservá capturas de pantalla, fechas, correos, mensajes sospechosos y registros. Limpiá la amenaza de forma segura y restaurá tu información únicamente desde copias de seguridad limpias.

🇦🇷
Canales oficiales en Argentina: Podés consultar los canales oficiales de Argentina.gob.ar para encontrar asesoramiento legal, reportar ciberdelitos y realizar las denuncias pertinentes ante la Unidad Fiscal Especializada en Ciberdelincuencia (UFECI).

Leyes, ética y responsabilidad

Marco Legal, Divulgación Responsable y Ley 26.388

La ciberseguridad no se limita al dominio de herramientas técnicas; exige un compromiso inquebrantable con la ética, el respeto por la privacidad ajena y el cumplimiento normativo:

Principios éticos no negociables:
  • No accedas jamás a cuentas, computadoras ni sistemas ajenos sin autorización expresa.
  • No robes, divulgues ni comercialices información confidencial ni datos personales.
  • No instales programas espía ni software de vigilancia en dispositivos de terceros sin su conocimiento y consentimiento.
  • No publiques vulnerabilidades adjuntando exploits o datos que dejen desprotegidas a las víctimas.
  • Si descubrís un fallo de seguridad, reportalo de forma ética al propietario del sistema o a través de su programa formal de divulgación coordinada (Responsible Disclosure / Bug Bounty).
  • Antes de cualquier prueba técnica, acordá por escrito el alcance, los objetivos permitidos y los horarios de la evaluación.

Física 2D y colisiones

Rigidbodies, Colliders, Triggers, Layers y Tags

Las físicas permiten que los objetos caigan por gravedad, colisionen entre sí y reboten de forma realista:

  • Rigidbody2D: Controla el movimiento físico, aceleración, masa y gravedad.
  • Collider2D: Delimita el contorno físico que choca. Sin un collider, los objetos se atravesarán.
  • Is Trigger: Permite detectar que un objeto atravesó una zona sin frenarlo físicamente (ideal para metas, monedas y zonas de muerte invisible).
C# — Métodos de Detección de Colisiones 
// Colisión física sólida (bloquea movimiento)
void OnCollisionEnter2D(Collision2D collision) 
{
    Debug.Log("Hubo una colisión sólida con: " + collision.gameObject.name);
}

// Entrada en una zona Trigger (atraviesa sin bloquear)
void OnTriggerEnter2D(Collider2D other) 
{
    Debug.Log("Entró en zona Trigger: " + other.gameObject.name);
}

Layers vs Tags:

Variables, Ciclo de Vida y Componentes

Métodos del Ciclo de Vida de MonoBehaviour

  • Awake(): Se ejecuta una sola vez al instanciarse el objeto, antes que Start. Ideal para inicializar referencias a componentes (GetComponent).
  • Start(): Se ejecuta antes del primer frame. Útil para configurar valores iniciales.
  • Update(): Se ejecuta una vez por cada frame dibujado. Ideal para leer entradas del teclado (Input).
  • FixedUpdate(): Se ejecuta en intervalos de tiempo fijos. Obligatorio para manipular físicas en Rigidbody2D.

Si difieren, Unity no podrá cargar el script como componente.

Cómo programar el movimiento de un personaje

Script Completo de Movimiento Horizontal con Rigidbody2D

Para juegos de plataformas 2D basados en físicas, lo más fluido es modificar la velocidad lineal del Rigidbody2D en FixedUpdate():

C# — PlayerMovement.cs 
using UnityEngine;

public class PlayerMovement : MonoBehaviour 
{
    public float speed = 5f;
    private Rigidbody2D rb;
    private float horizontal;

    void Awake() 
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update() 
    {
        // Lee las teclas A/D o Flechas (-1 a 1)
        horizontal = Input.GetAxisRaw("Horizontal");
    }

    void FixedUpdate() 
    {
        // Aplica velocidad horizontal manteniendo la vertical de la gravedad
        rb.linearVelocity = new Vector2(horizontal * speed, rb.linearVelocity.y);
    }
}
💡
Cómo probarlo: Creá el script PlayerMovement.cs, pegá el código, asignalo a tu GameObject Player con Rigidbody2D, presioná Play y movete con las flechas o teclas A y D. En versiones de Unity anteriores a 2023, utilizá rb.velocity en lugar de rb.linearVelocity.

Cómo programar un salto correctamente

Detección de Suelo y Aplicación de Impulso Físico

Un salto correcto requiere verificar que el personaje esté tocando el suelo antes de impulsarlo hacia arriba:

C# — PlayerJump.cs 
using UnityEngine;

public class PlayerJump : MonoBehaviour 
{
    public float jumpForce = 7f;
    private Rigidbody2D rb;
    private bool isGrounded;

    void Awake() 
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update() 
    {
        if (Input.GetKeyDown(KeyCode.Space) && isGrounded) 
        {
            // Reinicia la velocidad vertical antes de saltar
            rb.linearVelocity = new Vector2(rb.linearVelocity.x, 0f);
            rb.AddForce(Vector2.up * jumpForce, ForceMode2D.Impulse);
        }
    }

    void OnCollisionEnter2D(Collision2D collision) 
    {
        if (collision.gameObject.CompareTag("Ground")) 
        {
            isGrounded = true;
        }
    }

    void OnCollisionExit2D(Collision2D collision) 
    {
        if (collision.gameObject.CompareTag("Ground")) 
        {
            isGrounded = false;
        }
    }
}

Prefabs: crear objetos reutilizables

Plantillas Maestras para Obstáculos y Enemigos

Un Prefab es una plantilla preconfigurada de un GameObject que podés clonar e instanciar en múltiples lugares de tus escenas.

Imaginá que configurás un pincho peligroso con su Sprite, Polygon Collider 2D, script de daño y partículas. Al convertirlo en Prefab, podés colocar decenas de pinchos idénticos sin tener que configurarlos uno por uno.

Pasos para crear y usar un Prefab:

  2. Arrastralo desde la Hierarchy hasta la carpeta Assets/Prefabs en el Project.
  3. El icono se volverá azul, confirmando que es un Prefab.
  4. Para clonarlo, arrastralo desde la carpeta Project hacia cualquier parte del nivel.
  5. Cualquier cambio que apliques al Prefab original se propagará automáticamente a todas sus copias en el juego.

La cámara y el seguimiento del jugador

Script de Seguimiento Suave con Offset

En un juego de plataformas continuo, la cámara debe acompañar el avance horizontal del personaje:

C# — CameraFollow.cs 
using UnityEngine;

public class CameraFollow : MonoBehaviour 
{
    public Transform player;
    public float offsetX = 5f;

    void LateUpdate() 
    {
        if (player == null) return;

        // Actualiza posición en LateUpdate para evitar tirones (jittering)
        transform.position = new Vector3(
            player.position.x + offsetX,
            player.position.y,
            -10f // La cámara 2D debe mantenerse en Z = -10
        );
    }
}

Game Over, reinicio y pausa

Para pausar el juego se utiliza Time.timeScale = 0;, lo que congela el movimiento físico y las animaciones dependientes del tiempo. Al reanudar se restaura con Time.timeScale = 1;.

Cómo hacer un flyer que llame la atención
